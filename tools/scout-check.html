Scouting report check

ML part 3, read-only, localhost only. Loads the app's own scouting code (js/ml.js) and runs the self-check on a file: a game history copied from the live app (.json), or a harness run (.csv). Nothing is saved or sent anywhere.

Maxwell: 4FB,CH,SL,2FB,SP. Harness pitchers: 4FB,2FB,CH,CB (filled in automatically for a .csv).
